# BilldDesk 个人小程序体验原型

目标是两三名体验者，目前使用用户自己的小程序测试号扫码预览，不公开发布。原型采用 WebSocket 中继 + JPEG 压缩画面 + Canvas，未使用 live-player、TRTC 或声网 SDK。域名配置和手机到 Mac 的完整连接必须实际验证，不能用开发工具模拟器证明。

## 已实现的范围

- Mac 主屏幕，最大 1280×720、最多 5 帧/秒；适合查看状态、简单点击和文字操作。
- 点按单击、长按松开右键、滚动、文字输入、回车、退格、Esc。
- 每次开启生成 8 位连接码和随机临时密码。Mac 确认后才发送画面并允许控制。
- 每个会话同一时间一位体验者；两三人可以轮流连接。拒绝、超时、后台或断线后停止控制；会话两小时失效。
- 一帧收到并显示后才发送下一帧，避免弱网积压。断开时清理手机临时图片。
- 不含音频、文件传输、拖拽、组合快捷键、多屏切换。手机到 Mac 的连接与连续画面已实测；各项输入操作仍待逐项验收。

## 费用和账号

这条传输链路没有实时音视频 SDK 套餐费。仍需中继服务器、WSS 域名、有效 TLS 证书和流量；能否复用已有服务器及域名，要检查服务器余量、域名合法配置和备案状态。

估算示例：平均一张 JPEG 50 KB、5 帧/秒，经 base64 传输约 **1.2 GB/小时**（不含其他协议开销）。实际帧大小随画面变化，流量费用按供应商计费；最大帧限制并不代表日常流量。测试后可按可接受画质进一步降低帧率或分辨率。

注册入口：https://mp.weixin.qq.com/ 。选择小程序及个人主体，按实际后台要求完成身份验证。**无需提供 AppSecret**；本方案不调用需要 AppSecret 的微信服务端接口。请勿借用其他人的企业主体。

## 本地检查

```bash
npm ci --prefix mini-relay
node --test mini-relay/test.mjs mini-program/test.cjs test/mini-control.test.mjs
node mini-relay/server.mjs
```

中继默认仅监听 `127.0.0.1:4311`，WebSocket 路径 `/mini-control/`。Mac 可填写 `ws://127.0.0.1:4311/mini-control/` 检查本地链路；真机小程序要求合法的公网 WSS 地址。项目保留 `urlCheck: true`，不通过关闭域名或证书校验来验收体验版。

## 当前测试号预览步骤

1. `project.config.json` 已使用用户测试号 AppID。测试号扫码预览与普通小程序后台设为体验版是不同流程。
2. 微信开发者工具导入此目录，管理员扫码登录。项目不使用微信云开发。
3. 审阅 `ops/miniprogram/` 中的服务和 Nginx 示例，在已有 HTTPS 站点部署中继。中继目录独立执行 `npm ci --omit=dev`，Node 20 或更高；创建专用服务用户并核对 Node 路径和目录后再启用 systemd。
4. 在小程序后台的开发管理 / 开发设置中配置 **socket 合法域名**（例如 `wss://你的已配置域名`，填写域名而不是 `/mini-control/` 路径）。域名必须满足后台当前要求；本方案未承诺体验版免除域名或备案要求。
5. 按根目录 AGENTS.md 构建并安装原签名 Mac 包。打开 Mac 的“小程序体验连接”，填写公网 WSS 地址并开启。
6. 开发者工具点“预览”，手机扫码打开本次代码；修改后重新生成预览码并扫码。
7. Mac 点“复制连接信息”，手机在小程序顶部的粘贴框长按粘贴，自动填入 WSS 地址、连接码、临时密码，也可手动填写。跨设备剪贴板未同步时，用户可通过自己的私密方式将连接信息传到手机。
8. 手机点“请求连接”，Mac 确认“允许”后测试画面、点击、右键、中文输入、滚动、横竖屏、弱网恢复、后台断开和拒绝连接。

2026-10-07，经用户明确授权，中继已部署到现有服务器：`wss://desk.aduning.art/mini-control/`，客户端默认填入此地址。后台 socket 合法域名填写 `wss://desk.aduning.art`；能否通过后台的域名与备案要求仍需实际个人账号确认。

公网 TLS、连接确认、合成帧 / ACK、控制消息往返和断开已通过测试。原 Mac 签名身份已迁移，本机 Mac 新版已安装并注册中继。复制按钮与模拟器粘贴自动填入已验证。2026-10-08 修复手机画布初始化和旧图片缓存交替问题后，用户确认真实手机画面正常；各项输入操作仍待逐项验收。尚未上传普通体验版或公开发布。

## 数据处理

中继不落盘画面、密码或输入文字，也不打印连接消息。密码仅在会话内存中比较；屏幕 JPEG 每次解码使用不同文件名，避免手机反复读取旧图片缓存。解码后立即删除临时文件，断开时清理尚未完成解码的文件。传输必须经有效 TLS；服务器运营方技术上可以接触画面与输入，本原型没有应用层端到端加密。仅向自己可信的服务器部署。

Mac 的系统录屏和辅助功能权限分别控制画面和输入。主屏幕切换后停止输入并要求重新连接。手机黑边不映射到桌面坐标。
