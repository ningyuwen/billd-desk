# 远控工具栏与清晰度验证（2026-10-07）

## 修改

基线为 `develop` 的 `eee4b5953588c50d02857d738cc6e0b173956c4f`，工作分支 `p/ningyuwen/remote-toolbar-clarity`。

- 将画面上的 80×80 连接详情圆形入口及悬浮安卓操作区，移到画面外的 40px 顶部工具栏。视频使用剩余区域等比居中，初始窗口尺寸包含工具栏和原生标题栏；调整窗口时复用视频尺寸监听。留白不发送鼠标按下或移动。
- 详情仍按需展开，增加明确的“收起”，支持 Escape 关闭并返回入口焦点。本地详情控件的键盘输入不转发到手机；工具栏有焦点且详情关闭时保留原有 Alt+Shift 系统操作快捷键。
- Mac/网页连接入口及远控页默认从 1080P / 2000 kbps 改为 1440P / 12000 kbps。保持 60 帧上限和原有低延迟/编码处理，用户主动选较低参数仍优先应用。
- Android 主机初始短边分辨率和码率上限同步为 1440 / 12000；请求参数仍覆盖默认值，不对低分辨率屏幕放大。Android 版本为 0.1.28 / code 29。

## 实机验证

证据保存在被 Git 忽略的 `android-release/toolbar-clarity-20261007/`，不保存连接 URL、密码、SDP 或 ICE 数据。

- 主窗口 800×500：新默认 1440P / 60 帧 / 12 Mbps 可见；展开设置后能滚动到音频和共享区域，折叠后可连接已保存手机。证据：`main-800x500.png`、`main-settings-scroll.png`。
- 真实 Mac 控制 Android，连接路径直连 UDP。工具栏在宽窗口和 417×994 的竖屏窗口中均处于视频之外，六个安卓操作与详情入口可用。查看了原生放大窗口后的布局；未改主窗口约束。证据：`toolbar-wide.png`、`after-feed.png`、`details-narrow.png`。
- 点击详情/收起、Escape、焦点返回入口通过。详情展开期间输入 `x` 和 Escape，手机输入框保持原来的 `desk`，没有收到本地详情的按键。
- 新连接请求携带 1440 / 60 / 12000，详情页确认实际接收 1440×3200；旧参数同页回读为 1080×2400。
- 在同一个 417×994 接收窗口、同一静止详情页面切换旧参数和新参数，保存 `compare-1080-2m.png`、`compare-1440-12m.png`。`clarity-text-comparison.png` 是相同位置的文字裁剪，像素复制放大两倍，没有锐化。新参数的文字边缘更清楚；不是通过把显示窗口变大获得的对比。
- 60 秒原速窗口录屏 `remote-1440.mov` 包含返回、进入、向下及向上滚动、再次返回。操作位于录屏启动后约 4.78 / 10.78 / 11.97 / 17.90 / 18.28 秒，详细时间在 `record-actions.json`。`remote-1440-check.mp4` 截取 4.3–19.3 秒并裁去窗口阴影，无音频，未改变播放速度。逐帧图为 `back-contact.png`、`enter-contact.png`。
- 回看录屏，过渡中仍有短暂模糊和中间帧，之后画面恢复完整，没有观察到数秒卡住。点击进入详情与返回已用手机前台 Activity 回读确认，滚动能到评论并返回原位置。不能把这次局域网样本视为持续 60 fps 或弱网性能保证。
- 远程英文输入逐键发送 `desk` 后回读正确，清除测试文字并返回。连续快速批量四键出现过只保留部分字符，逐键输入正常；本次未修改原有 Android 文字编辑逻辑，不能宣称快速输入无丢字。
- 没有 Android 布局改动；本轮没有重新验证 Android 作为控制端的横竖屏布局、其他手机、Windows/Linux、TURN/弱网。未部署线上网页或上传正式下载渠道。
