# Mac 临时保活

双击同目录的 `keep-awake.command`，或在终端运行：

```bash
./ops/keep-awake.command
```

默认运行30分钟，每150秒向 macOS 发送一次用户活跃请求，同时申请临时保持屏幕和系统唤醒。使用系统自带的 `caffeinate`，不会真实点击鼠标，不需要鼠标自动化权限。

按 **Control+C** 停止，到时也会自动退出。可指定运行分钟数和间隔秒数，例如运行60分钟、每180秒一次：

```bash
./ops/keep-awake.command 60 180
```

仅检查参数、不启动保活：

```bash
./ops/keep-awake.command --dry-run
```

这不是修改锁屏时间的工具。公司管理描述文件中的强制锁屏策略可能不受普通电源保活请求影响；本脚本不会修改或移除描述文件，也不会解锁已锁定的屏幕。当前机器的 `Screensaver (5m)` 策略仍需由管理方调整。语法与参数检查不能证明该策略下的实际保活效果。

2026-10-06 在当前 Mac 进行了6分钟连续观察：最后一次输入后的系统空闲时间达到452秒，期间未锁屏，安卓仍持续收到远程视频。系统在11:00:09检查到空闲324.5秒，日志明确显示 `caffeinate` 的 `PreventUserIdleDisplaySleep` 请求阻止了屏幕保护启动。本次脚本保活有效；没有修改管理描述文件，也未验证其他机器或整个30分钟运行周期。远程连接验证结果见 `remote-validation-20261006.md`。
